Automated Valuation Model

Built an end-to-end machine learning pipeline to predict California single-family home closing prices using 186K+ MLS transaction records.

GitHub

About Project

Developed an Automated Valuation Model (AVM) to estimate closing prices for California single-family homes using MLS transaction data. The project focused on building and evaluating machine learning models using chronological data splits, feature engineering, and hyperparameter tuning.

Key Contributions

  • Prepared 186K+ single-family home records from 369K+ raw MLS transactions through filtering, cleaning, and preprocessing.
  • Engineered property and geospatial features, including bed-to-bath ratio, property age, and school district assignments using GeoPandas.
  • Compared and tuned Linear Regression, Random Forest, Extra Trees, and HistGradientBoosting using chronological train-validation-test splits.
  • Improved test R² from 0.801 to 0.822 and reduced RMSE from approximately $685K to $649K through feature selection and hyperparameter tuning.
