The Vanishing Arctic

Built an interactive scrollytelling data visualization exploring Arctic sea ice decline, climate change, and its impact on polar bear habitats.

Technologies used

  • D3.js
  • JavaScript
  • HTML
  • CSS
  • JSON

Project type

  • Data Visualization
  • Scrollytelling
  • Climate Data
  • Team Project

Overview

  • Created a web-based storytelling experience focused on Arctic sea ice loss.
  • Visualized historical sea ice changes through interactive scroll-based sections.
  • Used climate and temperature datasets to communicate environmental change clearly.

Key features

  • Interactive scrollytelling layout with year-based Arctic sea ice changes.
  • D3-powered map and data visualizations for Arctic climate storytelling.
  • Responsive visual design combining data, narrative, and environmental context.
